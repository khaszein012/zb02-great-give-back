# Episode 3 — art master prompt

Paste the **style block** and the **character block** at the top of every prompt, then add
one asset line. Lovable's image generator holds a consistent look when the style wording is
identical each time, so do not paraphrase between runs.

---

## 1. Style block — paste into every prompt

```
Children's storybook illustration, soft gouache and watercolour painted on textured paper.
Warm palette: mustard yellow, terracotta, sage green, dusty blue, cream, with deep navy for
shadows. Rounded friendly shapes, gentle soft outlines, no harsh black lines. Cosy, calm,
welcoming mood. Even soft lighting, no dramatic shadows. Flat-ish painted shading, visible
paper grain, hand-made feel.

STRICT: absolutely no text, no lettering, no words, no captions, no labels, no numbers,
no speech bubbles, no signage. Any surface that would normally carry writing must show
abstract squiggles or blank space instead.
```

## 2. Character block — paste when a character appears

```
ZABYR: a 10-year-old boy detective, warm brown skin, short curly dark hair, tan trench coat
over a mustard-orange shirt, brown trousers, brown boots, small brass magnifying glass in
his pocket. Friendly, curious, unbothered expression.

PIP: a small floating brass camera the size of a sparrow, with two large round expressive
eyes on the front, tiny thin arms, a soft warm glow. Adorable and friendly, never
mechanical or scary. Floats at shoulder height.

MISTER MAGPIE: a tall glossy black-and-white magpie standing upright like a person, wearing
a brown tweed waistcoat with brass buttons, holding a small paper bag of shiny objects.
Smug but not frightening. Comical, never menacing.
```

## 4. Rules to keep the set coherent

1. **Never** let the model write anything. Text is the single most common failure, and a
   single word on a sign breaks the look of the whole set.
2. Generate all nine chapters in one sitting with the identical style block; re-rolling one
   later drifts the palette.
3. Keep Zabyr and Pip in the same pose vocabulary — standing, looking, holding. Avoid action
   poses, which drift his face between images.
4. The map is the only asset where **ordering matters**: districts must run left to right in
   the order Garage → Bench → Vault → Green → Shop → Globe → Nest. Exact positions are
   hand-tuned in CSS afterwards, so approximate placement is fine.
5. Chapter images are displayed at **4:3**, so generate at 1536×1152 and keep important
   detail away from the top and bottom 12% of the frame.
6. Mister Magpie should look **comical, never threatening** — this is a game for young
   children.
